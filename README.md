## 🙋‍♂️ About Me

Think of me as the person who builds the **immune system for AI** — I'm a Responsible AI Engineer at Infosys, and my job is making sure LLMs don't go rogue in production. I catch jailbreaks, mask PII before it leaks to external APIs, red-team agentic systems, and fine-tune models to be both safe *and* genuinely useful (because "safe but useless" doesn't count).

- 🔐 I build real-time guardrails that sit between enterprise developers and LLMs — intercepting prompt injections and toxic outputs before anyone notices they happened
- 🤖 I've stress-tested AI systems so aggressively that I managed to improve safety benchmarks by **34%** without making the model a boring brick
- 🧠 My sweet spot is where alignment research meets production engineering — where whitepaper theory collides with a 3am `RuntimeError` on a GPU cluster  
- 🏋️ Running SFT jobs on **H100/B200 clusters** is basically my version of going to the gym
- 🎖️ One of the first engineers to earn the **Claude Certified Architect** credential from Anthropic — I work *with* the models I protect
